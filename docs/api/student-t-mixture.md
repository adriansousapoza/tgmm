# StudentTMixture API

`StudentTMixture` is a robust alternative to `GaussianMixture` (Peel &
McLachlan, 2000): each component is a multivariate Student-t with mean,
scale matrix, and degrees of freedom, fit by ECM. See the [Other Mixture
Families](../user-guide/other-mixture-families.md) user guide page for
when to reach for it over `GaussianMixture`.
